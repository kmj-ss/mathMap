# mathMap

선생님 한 명이 문제를 실시간으로 내고, 접속한 학생들이 동시에 푸는 수학 퀴즈 사이트입니다.
PC, 아이패드, 갤럭시 탭, 크롬북 등 브라우저만 있으면 앱 설치 없이 접속할 수 있습니다.

- 서버: Java 21, Spring Boot 3.5
- 실시간 통신: WebSocket (끊기면 자동 재연결)
- 화면: HTML / CSS / JavaScript (프레임워크 없음)

## 사용 흐름

1. 선생님이 사이트 첫 화면(`/`)에서 비밀번호를 입력하고 **방 만들기** (예: "3학년 2반 수학")
2. 방마다 학생 공유 주소(`/r/방주소`)가 생깁니다. **주소 복사**로 학생들에게 보냅니다.
3. 학생은 공유 주소로 들어와 학급 번호와 이름만 입력하면 그 방에 입장합니다. 다른 방에는 들어갈 수 없습니다.
4. 선생님은 방의 수업 화면(`/t/방주소`)에서 문제를 내고 진행합니다.

| 주소 | 누가 |
|---|---|
| `/` | 선생님: 비밀번호 확인, 방 만들기, 내 방 목록 |
| `/t/방주소` | 선생님: 그 방 수업 진행 화면 |
| `/r/방주소` | 학생: 그 방 입장 |

방 주소는 추측할 수 없는 무작위 10자리이고, 24시간 동안 쓰지 않은 방은 자동으로 정리됩니다.

## 기능

**학생**
- 공유받은 주소에서 학급 번호, 이름으로 입장. 같은 번호+이름으로 다시 들어오면 점수가 이어집니다.
- 문제가 없으면 대기 화면, 문제가 올라오면 바로 표시됩니다.
- 주관식은 답 입력, 객관식은 보기 선택. 한 문제에 한 번만 제출할 수 있습니다.
- 맞으면 "정답입니다! +3점", 틀리면 선생님이 정한 문구(기본 "틀렸습니다")가 뜹니다.
- 선생님이 마감하면 정답이 공개되고, 다음 문제를 기다립니다.

**선생님**
- 방 여러 개 만들기/삭제, 방마다 공유 주소 복사
- 문제 등록: 직접 입력 또는 이미지, 주관식(정답 여러 개 인정 가능) 또는 객관식, 배점(기본 3점), 오답 문구
- 출제 전 문제 수정/삭제, 원하는 문제 바로 출제
- "다음 문제 출제"로 모든 학생이 함께 넘어감, "마감 및 정답 공개"
- 오른쪽 패널: 접속 상태, 학생별 점수, 현재 문제 제출 여부(O/X). 접기/펼치기 가능
- 학생 강퇴 (같은 번호+이름으로 재입장 차단, 필요하면 "입장 허용")
- 점수 엑셀(.xlsx) 다운로드
- 새 수업 시작 (그 방의 학생과 점수 초기화)

## 보안

- 학생은 공유받은 방에만 입장할 수 있고, 방 주소는 추측할 수 없는 무작위 값입니다.
- 정답은 서버에만 있고 채점도 서버에서만 합니다. 마감 전에는 정답이 학생 브라우저로 전송되지 않습니다.
- 점수는 서버가 계산합니다. 학생은 "답"만 보낼 수 있습니다.
- 방 만들기와 선생님 기능은 비밀번호로 로그인한 세션에서만 동작하고, 서버가 모든 요청마다 확인합니다. 주소창에 `/api/teacher/...`, `?score=100` 등을 넣어도 동작하지 않습니다.
- 로그인 시 세션 id 교체, 로그인/입장 시도 횟수 제한, 같은 사이트에서 보낸 요청만 허용, 다른 사이트의 실시간 연결 차단
- 보안 헤더(CSP, X-Frame-Options 등), 쿠키는 HttpOnly + SameSite=Strict (+ HTTPS에서 Secure)
- 화면에 표시하는 글자는 모두 텍스트로만 넣어서 이름이나 답에 스크립트를 넣어도 실행되지 않습니다.
- 이미지 업로드는 선생님만, PNG/JPG/GIF/WEBP, 5MB 이하, 파일 내용으로 형식 확인

## VS Code에서 실행하기

1. JDK 21 설치 (예: https://adoptium.net)
2. VS Code 확장 설치: **Extension Pack for Java**, **Spring Boot Extension Pack** (폴더를 열면 추천 알림이 뜹니다)
3. 이 저장소를 clone 해서 VS Code로 열기
4. 왼쪽 "실행 및 디버그"에서 **mathMap 실행** 선택 후 실행 (로컬 테스트용 선생님 비밀번호는 `.vscode/launch.json`의 `local-test-1234`)
5. 브라우저에서 `http://localhost:8080/` 접속 → 비밀번호 입력 → 방 만들기 → 공유 주소로 학생 접속

같은 와이파이의 태블릿으로 테스트하려면 공유 주소의 `localhost`를 내 PC의 IP로 바꿔서 접속하면 됩니다.

터미널에서 실행하려면 Maven이 필요합니다.

```bash
mvn test                      # 테스트
mvn spring-boot:run           # 실행
mvn package                   # target/mathmap.jar 생성
```

## 환경변수

| 이름 | 설명 |
|---|---|
| `MATHMAP_TEACHER_PASSWORD` | 선생님 비밀번호. 꼭 설정하세요(8자 이상 권장). 비어 있으면 실행할 때마다 임시 비밀번호를 서버 로그에 출력합니다. |
| `MATHMAP_SECURE_COOKIE` | HTTPS로 배포할 때 `true` (Dockerfile 기본값 true) |
| `PORT` | 서버 포트 (기본 8080, 클라우드가 자동 지정) |

## 클라우드 배포 (Render 추천)

Render는 GitHub 저장소를 연결하면 자동으로 빌드하고, `https://<이름>.onrender.com` 주소에 HTTPS 인증서까지 붙여줍니다.

1. https://render.com 가입 (GitHub 계정으로 로그인)
2. **New → Blueprint** 선택 후 `mathMap` 저장소 연결 (저장소의 `render.yaml`을 읽습니다)
3. `MATHMAP_TEACHER_PASSWORD` 값 입력 후 배포
4. 배포가 끝나면 나오는 `https://...onrender.com` 주소로 접속해서 방을 만들고, 방의 공유 주소를 학생에게 보냅니다

요금제 참고
- **Starter(유료)**: 항상 켜져 있어 수업용으로 추천 (`render.yaml` 기본값)
- **Free**: 15분 동안 접속이 없으면 잠들고, 깨어날 때 수업 기록이 사라집니다. 테스트용이면 `render.yaml`의 `plan`을 `free`로 바꾸세요.

GitHub에 새로 올리면(push) 자동으로 다시 배포됩니다.
도메인은 없어도 되고, 원하면 Render 설정의 Custom Domains에서 연결할 수 있습니다.

## 알아둘 점

- 수업 데이터(방, 학생, 점수, 문제, 이미지)는 서버 메모리에만 있습니다. 서버가 재시작되면 사라지므로 **수업이 끝나면 엑셀을 다운로드**하세요.
- 서버는 1대(인스턴스 1개)로 실행해야 합니다.
